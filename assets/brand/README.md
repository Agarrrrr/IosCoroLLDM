# Variantes de identidad Coro LLDM

Todas las imágenes parten del emblema oficial del Social Kit y conservan su geometría original.

- `app-icon-rounded.png`: icono principal cuadrado redondeado.
- `emblem-transparent.png`: emblema sin fondo para composiciones.
- `icon-light.png`: fondo marfil para tema claro.
- `icon-dark.png`: fondo del oscuro normal (`#11161C`).
- `icon-oled.png`: fondo negro puro.
- `icon-sepia.png`: fondo sepia (`#F4ECD8`).
- `icon-circular.png`: avatar circular.
- `icon-monochrome.png`: emblema blanco monocromático.
- `android-foreground.png` y `android-background.png`: capas para icono adaptativo Android.
- `splash-light.png` y `splash-dark.png`: emblema para pantallas de carga.

El script reproducible está en `tools/generate_brand_variants.mjs` y usa la fuente oficial en `website/dist/social-kit/`.
