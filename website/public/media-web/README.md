# Media Web (Repertorio y Videos para la Web)

Esta carpeta está reservada exclusivamente para los videos finales optimizados (MP4/WebM) y miniaturas web que se deseen desplegar directamente dentro del sitio web (www.lldmcoro.com).

Toda la producción en bruto (crops 4:3, fondos de video, campañas de redes, audios de trabajo) se gestiona en la carpeta raíz `/social-media/` para mantener el bundle web ligero y rápido.
